# 第五章 系统部署与运行说明

## 5.1 运行环境需求

| 类别 | 要求 |
| --- | --- |
| 服务器硬件 | 双核 CPU / 4GB 内存 / 80GB 磁盘 / 10Mbps 带宽 |
| 服务器软件 | Windows Server 2019、IIS 10、SQL Server 2019、.NET Framework 4.7.2、Visual Studio 2019 |
| 客户端 | Chrome / Edge / Firefox，分辨率 1366×768 及以上 |

## 5.2 安装、配置与发布步骤

1. 安装操作系统与所需软件环境；
2. 执行 `database/CampusPartTime.sql` 创建数据库及表结构；
3. 配置连接字符串（Web.config 中的数据库连接，示例见部署文档）；
4. 使用 Visual Studio 编译并发布到 IIS；
5. 浏览器访问系统，完成初始化数据配置。

## 5.3 版本控制

项目全程使用 Git 进行版本管理，遵循 Conventional Commits 规范前缀（feat / docs / refactor / test / chore），具体实践见第七章。
