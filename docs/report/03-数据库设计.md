# 第三章 数据库设计

## 3.1 概念结构设计（E-R 图）

系统包含 6 个实体：**学生（student）、商家（employer）、管理员（admin）、兼职岗位（job）、申请记录（application）、评价（comment）**，实体间存在 6 条 1:N 联系：

- 商家 1:N 岗位
- 学生 1:N 申请记录
- 岗位 1:N 申请记录
- 学生 1:N 评价
- 岗位 1:N 评价

## 3.2 逻辑结构设计（关系模型）

6 个关系模式均满足第三范式（3NF）：

- student(stu_id, stu_name, stu_gender, stu_major, stu_phone, stu_password, ...)
- employer(emp_id, emp_name, emp_contact, emp_phone, emp_password, ...)
- admin(adm_id, adm_name, adm_password, ...)
- job(job_id, emp_id, job_title, job_type, salary, work_time, status, ...)
- application(app_id, stu_id, job_id, app_time, status, ...)
- comment(com_id, stu_id, job_id, score, content, com_time, ...)

## 3.3 物理结构设计

SQL Server 2019 建库 `CampusPartTime`，共 6 张表，主要设计要点：

- 主键：各表自增主键；
- 外键：application / comment / job 关联对应实体表；
- 索引：5 组索引覆盖常用检索字段（岗位类型、薪资、发布时间、申请状态等）；
- 约束：默认值、非空、检查约束（如性别、评分范围）。

## 3.4 数据字典

6 个实体逐字段定义数据类型、长度、默认值、取值范围与说明，详见系统设计文档第三章 4.1~4.6。
