# 第四章 系统详细设计与实现

## 4.1 数据库服务器端实现

### 4.1.1 视图 v_job_detail

将 `job` 与 `employer` 连接，仅展示审核通过的岗位，供前台检索使用。

### 4.1.2 存储过程 proc_apply_job

在线申请岗位，使用事务保证数据一致性，包含状态检查与重复申请校验，通过状态码返回结果：

| 状态码 | 含义 |
| --- | --- |
| -1 | 岗位不存在或已下架 |
| -2 | 岗位已招满 |
| -3 | 重复申请 |
| 1 | 申请成功 |

### 4.1.3 触发器 trg_job_after_apply

在申请记录插入后自动触发：当岗位申请人数达到招聘人数时，自动将岗位状态置为「已招满」，避免人为漏改。

## 4.2 应用服务器端实现

- 使用 C# + ADO.NET 实现四类代表功能：岗位发布（录入）、岗位下架（逻辑删除）、条件检索、修改并重置审核状态；
- 登录页使用 HTML / CSS / JavaScript 实现前端校验（非空、格式、密码强度）；
- 共 7 个主要界面页面，控件类型超过 10 种，满足实验要求。
