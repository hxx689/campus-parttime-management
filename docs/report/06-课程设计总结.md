# 第六章 课程设计总结

本次课程设计完成了校园兼职招聘管理系统，实现了 6 张数据表、1 个视图、1 个存储过程、1 个触发器及 7 个主要功能页面，覆盖岗位发布、审核、检索、申请、录用与评价的完整业务流程。

## 6.1 主要难点与解决方案

| 难点 | 解决方案 |
| --- | --- |
| 申请数据一致性 | 存储过程 `proc_apply_job` 使用事务机制，保证并发申请下数据正确 |
| 岗位满员自动维护 | 触发器 `trg_job_after_apply` 在申请插入后自动更新岗位状态 |
| 多表关联检索效率 | 视图 `v_job_detail` 预连接岗位与商家信息，过滤审核通过数据 |

## 6.2 不足与改进方向

- 系统未适配移动端，后续可增加响应式布局或小程序端；
- 岗位审核依赖人工，后续可引入关键词自动审核；
- 缺少消息推送机制，后续可接入站内信或短信通知。

## 6.3 收获

通过本次实践，掌握了 E-R 图与关系模式转换、SQL Server 视图 / 存储过程 / 触发器等高级对象的使用，以及 ADO.NET 分层开发的完整流程；同时借助 Git 完成了项目的版本控制，理解了规范化提交与迭代开发的价值。
