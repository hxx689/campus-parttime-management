# 第二章 系统总体设计

## 2.1 系统架构

系统采用 B/S 三层架构：

```
表现层（ASP.NET Web 窗体）
    ↓
业务逻辑层（BLL）
    ↓
数据访问层（DAL，ADO.NET + SQL Server）
```

- **表现层**：负责页面展示与用户交互，包含登录、注册、岗位检索、申请、评价等 7 个页面；
- **业务逻辑层**：负责业务规则处理，如申请校验、状态流转；
- **数据访问层**：通过 ADO.NET 与 SQL Server 交互，封装增删改查。

## 2.2 功能模块划分

| 模块 | 核心职责 | 涉及数据表 |
| --- | --- | --- |
| 用户管理 | 学生 / 商家 / 管理员注册、登录、信息维护 | student / employer / admin |
| 岗位管理 | 岗位发布、审核、检索、下架 | job |
| 申请管理 | 在线申请、录用状态管理 | application |
| 评价管理 | 录用后双方互评 | comment |
| 系统管理 | 用户权限、数据统计 | 全部 |

## 2.3 用户角色与权限

| 角色 | 主要权限 |
| --- | --- |
| 学生 | 注册登录、检索岗位、在线申请、评价 |
| 商家 | 发布岗位、查看申请、录用、评价学生 |
| 管理员 | 审核岗位、用户管理、数据统计 |
