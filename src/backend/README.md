# 后端项目骨架（BLL / DAL / Web）

## 目录说明

```
src/backend/
├── BLL/    # 业务逻辑层：岗位管理、申请管理、用户管理等业务规则
├── DAL/    # 数据访问层：ADO.NET 封装，提供增删改查通用方法
└── Web/    # 表现层：ASP.NET Web 窗体页面与代码后置
```

## 分层职责

- **DAL（数据访问层）**：封装数据库连接与基础 CRUD，参数化查询防 SQL 注入；
- **BLL（业务逻辑层）**：处理业务规则（申请校验、状态流转、权限判断）；
- **Web（表现层）**：页面展示与用户交互，调用 BLL 完成业务。
