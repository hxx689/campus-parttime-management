# 前端资源骨架

## 目录说明

```
src/frontend/
├── css/     # 样式文件（主色 #2C6CB0 统一规范）
├── js/      # 前端脚本（表单校验、交互逻辑）
└── pages/   # 页面文件（登录、注册、岗位检索、发布、审核、申请记录、评价）
```

## 页面清单

| 页面 | 路径（规划） |
| --- | --- |
| 登录页 | pages/login.html |
| 学生注册页 | pages/register.html |
| 岗位检索页 | pages/job_search.html |
| 岗位发布页 | pages/job_publish.html |
| 岗位审核页 | pages/job_audit.html |
| 申请记录页 | pages/application.html |
| 评价页 | pages/comment.html |

> 注：本仓库先提交目录骨架与页面规划，页面实现按实验要求逐步补充。
